# Ubica tu paleta · Villaizán

Mapa de puntos de venta de Paletas Villaizán en Lima.

- La lista de bodegas se lee del Google Sheet configurado en `CONFIG.SHEET_ID` dentro de `index.html`.
- Para ocultar una bodega, pon NO en la columna ACTIVO del Sheet.
- El número de WhatsApp para distribuidores va en `CONFIG.WHATSAPP`.
